# 법령 조문 캡처 (law_capture) v1.0.0

국가법령정보센터에서 **사건 시점에 시행 중이던** 법령·고시 조문을 찾아,
쟁점 문구에 빨간 밑줄을 긋고, 그림으로 잘라 **한글 문서**에 넣어 주는 프로그램입니다.

건설 하자소송 준비서면·의견서 작성용입니다.
손으로 하면 조문 하나에 3~5분 걸리는 일을 자동으로 처리합니다.

---

## 이 프로그램이 하는 일

1. 법령·고시 이름을 검색하고, 원하는 **시점의 개정본**을 고릅니다
2. 지정한 조문만 PDF로 받습니다
3. 쟁점 문구에 **빨간 밑줄**을 긋습니다
4. 머리말·꼬리말을 빼고 본문만 **그림**으로 자릅니다
5. 한글에 넣어 **크기·테두리·캡션**까지 맞춥니다

---

## 준비물 (한 번만)

| 항목 | 설명 |
|---|---|
| Windows | 회사 PC / 개인 PC |
| Python 3.10 이상 | 스크립트 실행 |
| 한글(한컴오피스) | 그림 삽입용 (COM) |
| Playwright Chromium | PDF 다운로드용 숨은 브라우저 |

의존성 설치 예:

```bash
pip install playwright pymupdf pyhwpx pillow
python -m playwright install chromium
```

자세한 설치 기록은 [설치목록.md](설치목록.md)를 보세요.

## 실행 방법

프로젝트 폴더에서 `법령캡처_실행.pyw` 를 **더블클릭**하면 창이 뜹니다.

또는:

```bash
cd C:\Users\USER\Desktop\DEV\law_capture_to_hwp
python main.py
```

## 화면 사용법 (처음부터 끝까지)

아래 순서대로 하면 됩니다.

### 1) 법령·고시 찾기

1. **법령/고시명** 칸에 이름 일부만 적습니다.  
   예: `하자판정기준`, `공동주택관리법`
2. **[검색]** 을 누릅니다 (Enter 키도 됩니다).
3. 여러 건이 나오면 **바로 아래 목록**에서 원하는 것을 고릅니다.  
   (이름에 ‘주택’이 들어간 다른 법이 먼저 나올 수 있습니다.)

### 2) 즐겨찾기 (자주 쓰는 법)

- 메인 화면 **즐겨찾기** 목록에서 바로 고를 수 있습니다.
- **[설정]** 을 누르면 설정 창이 열립니다.
  - 창 안에서 법령을 **검색 → [추가]**
  - 목록에서 고른 뒤 **[제거]** / **[적용]**
  - **[적용]** 또는 목록 **더블클릭** → 메인 화면에 그 법령이 선택됩니다
- 저장 위치: 프로젝트 폴더의 `user_favorites.json`  
  (개정본 번호는 저장하지 않습니다. 판은 아래 ‘시점’에서 고릅니다.)

### 3) 어느 시점의 판?

세 가지 중 하나를 고릅니다.

| 방식 | 언제 쓰나 | 하는 일 |
|---|---|---|
| **특정 시점 하나** | 사건 발생일·계약일 하나 | 그날에 시행 중이던 판 1개 |
| **기간 안의 모든 개정본** | 일정 기간 동안 바뀐 판을 모두 | 시작일~종료일 사이 시행 판들 |
| **전체 기간** | 제정부터 현행까지 | 전부 (많을 수 있음 · 주택법 100개 이상) |

날짜를 맞춘 뒤 **[그 시점 판 찾기]** / **[개정본 찾기]** / **[전체 개정본 찾기]** 를 누릅니다.

### 4) 캡처할 개정본 체크

- 나온 목록에서 **체크된 것만** 캡처합니다.
- **[전체 선택]** 으로 한 번에 켜고 끌 수 있습니다.
- **전체 기간** 모드는 처음에 전부 꺼져 있습니다. 필요한 것만 켜세요.  
  (실수로 수십~백 장을 만들지 않기 위함입니다.)

### 5) 조문 번호와 빨간 밑줄

**조문 번호** 예:

| 입력 | 의미 |
|---|---|
| `1` | 제1조 |
| `1, 2` | 제1조와 제2조 |
| `1-3` | 제1조~제3조 |
| `32의2` | 제32조의2 (가지번호) |

**미리보기**

1. 조문 번호를 넣고 **[미리보기]** → 오른쪽 칸에 조문 글자가 나옵니다.
2. 조문을 모를 때는 **[전체보기]** → 그 판의 본문 전체가 나옵니다.  
   (표·별표는 글자로 안 올 수 있습니다 → **[원문 보기]**)
3. 밑줄 칠 부분을 **마우스로 드래그**하면 빨간 밑줄 목록에 들어갑니다.  
   미리보기에서 **빨간 표시를 다시 클릭**하면 그 밑줄만 취소됩니다. (왼쪽 목록의 **삭제**와 같습니다.)
4. **전체보기에서 드래그**하면 **조문 번호 칸도 자동으로** 채워집니다.
5. 긴 글은 헤더 **[찾기]** 또는 **Ctrl+F** 로 찾을 수 있습니다 (노란 표시).

같은 문구가 여러 번 나오면 `균열 [2번째]`처럼 순번이 붙습니다.

**캡션·테두리**는 기본으로 켜져 있습니다. 필요 없으면 체크를 끄세요.

### 6) 목록에 담기 → 실행

1. **[＋ 이 조건을 목록에 담기]** 로 작업을 쌓습니다.  
   (조문·밑줄을 바꿔가며 여러 줄을 담을 수 있습니다.)
2. 아래 **[실행]** 을 누릅니다.
3. 진행 화면이 보입니다. **그동안 컴퓨터를 건드리지 마세요.**
   - 브라우저는 **화면에 안 뜹니다** (뒤에서 동작).
   - 한글은 잠깐 열렸다 우리 작업용만 닫힙니다.  
     **이미 열어 둔 한글 문서는 건드리지 않습니다.**
4. 완료 화면에서 결과 파일 위치를 확인합니다.  
   조문 하나가 실패해도 나머지는 계속 돌고, 실패한 이유만 한국어로 표시됩니다.

### 7) 원문 보기

미리보기 헤더의 **[원문 보기]** 를 누르면,
지금 고른 판의 **국가법령정보센터** 페이지가 기본 브라우저로 열립니다.
표·별표를 눈으로 확인할 때 쓰세요.

## 결과 파일이 어디에 생기나

- 기본 저장 폴더: 프로젝트 안 `out\`
- 기존 한글 문서를 고르면 **원본은 그대로** 두고  
  `원본이름_캡처본.hwp` 로 **새로** 저장합니다.

### 회사 PC 보안 프로그램

바탕화면·내 문서에 한글이 직접 저장하면 **오류 없이 조용히 실패**하는 환경이 있습니다.
이 프로그램은 한글에는 **임시 폴더**에 저장시킨 뒤, 파이썬이 `out\` 등으로 옮깁니다.
보안 설정은 건드리지 않습니다.

## 명령줄로 실행하기 (선택)

화면 없이 여러 건을 돌릴 때:

```bash
python run_from_command_line.py --name 하자판정기준 --from 2024-01-01 --to 2026-12-31 --article 1 --underline "제1조(목적) 이 기준은" --article 7 --underline "균열 폭이 0.3mm 이상인 경우" --out "out\결과.hwp"
```

- `--underline` 은 **바로 앞의 `--article`** 에만 적용됩니다.
- 시점 하나: `--date 2025-06-01`
- 기존 문서에 넣기: `--into 준비서면.hwp` (원본 유지, `--out` 위치에 새 파일)

## 설정 바꾸기

`config.py` 한 파일만 열면 됩니다.

| 값 | 기본값 | 설명 |
|---|---|---|
| `APP_VERSION` | `1.0.0` | 프로그램 버전 |
| `UNDERLINE_THICKNESS_IN_POINTS` | 2.0 | 밑줄 두께 |
| `UNDERLINE_GAP_BELOW_TEXT_IN_POINTS` | 1.2 | 글자 아래에서 얼마나 내려 그을지 |
| `PICTURE_WIDTH_IN_MILLIMETERS` | 155.0 | 그림 가로 폭 |
| `PICTURE_BORDER_WIDTH_IN_MILLIMETERS` | 0.12 | 그림 테두리 |
| `CAPTION_FONT_NAME` | 휴먼명조 | 캡션 글꼴 |
| `CAPTION_FONT_SIZE_IN_POINTS` | 10 | 캡션 크기 |
| `CAPTION_SIDE` | Top | 캡션 위치 (위/아래) |
| `SHOW_BROWSER_WINDOW` | False | True면 PDF 받을 때 크롬 창 표시 |

버전 올릴 때는 [docs/VERSION_RELEASE_CHECKLIST.md](docs/VERSION_RELEASE_CHECKLIST.md) 를 따르세요.

## 알아두면 좋은 것

- **한글을 강제 종료하지 마세요.** 작업 중인 문서가 날아갈 수 있습니다.
