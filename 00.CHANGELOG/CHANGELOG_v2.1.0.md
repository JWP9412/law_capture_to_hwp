# CHANGELOG v2.1.0

## 2026-11-10 — 2.1.0

### 수정

- **법령·고시 검색 복구**: 법제처 공개 API를 주소에 붙여 묻던 방식(GET)이 PC 주소 검증에 막혀, 메인 화면·즐겨찾기 설정에서 `주택법` 등을 “찾지 못했습니다”로 잘못 안내하던 문제를 고쳤다. 같은 내용을 본문으로 보내는 방식(POST)으로 바꾼다.
- 공개 API가 인증·필수값 문제로 거절한 응답을 “검색 결과 없음”으로 넘기지 않고, 통로 이상으로 구분한다. (예비 수단인 한글 주소 검색으로 넘어갈 수 있게 한다.)
- 조문 미리보기용 공개 API 조회도 같은 방식으로 다시 동작한다.
