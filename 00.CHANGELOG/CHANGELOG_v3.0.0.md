# CHANGELOG v3.0.0

## 2026-11-20 — 3.0.0

국가법령정보센터 2026 리뉴얼에 맞추고, 화면을 사이트와 비슷한 느낌으로 새로 꾸민 큰 버전이다.

### 추가

- **법령정보센터 스타일 화면**: 진남·파랑 색, 글꼴(Pretendard GOV → Noto Sans KR → 맑은 고딕), 머리 띠, 둥근 모서리 버튼·입력칸·카드.
- **둥근 모서리**: `ui/rounded_shapes.py` 로 버튼·입력칸·토글 그림을 만들고, 카드는 `RoundedCardShell` 로 그린다.
- **미리보기 본문 강조**: 조 제목 굵게, 개정 표시는 파랑.
- **디자인 목업**: `docs/mockup/` (HTML·적용 후 화면 그림).
- **속도 측정**: `spike/check_ui_speed.py`.

### 수정

- **PDF 저장 창(리뉴얼 대응)**: 저장 버튼을 바깥 팝업(`#…OutPutDivWrite`)에서 찾고, 고시 PDF 단추를 `#FileSavePdf1` 로 맞춘다. 고시 저장 직전 부칙·별표를 끈다.
- **반응 속도**: 둥근 그림 최소 크기를 160픽셀로 키워 버튼 hover·창 크기 조절이 크게 빨라졌다. (작으면 ttk가 조각을 수십 번 붙여 20배 느려짐)
- **개정본 휠**: 목록이 짧으면 창 전체 스크롤, 길면 목록만 스크롤. 다시 맞출 때 맨 위로 튕기지 않게 했다.
- **창 크기 조절**: 폭이 10픽셀 이상 바뀔 때만 안쪽·버튼을 다시 맞춰 드래그 중 버벅임을 줄였다.
