# CHANGELOG v1.0.0

## 2026-08-05 — 첫 공개 버전 1.0.0

### 기능

- 국가법령정보센터에서 법령·고시 검색, 시점별 개정본 선택
- 조문 PDF 다운로드 → 빨간 밑줄 → 그림 잘라내기 → 한글 삽입(캡션·테두리)
- 미리보기 / **전체보기**, 드래그로 밑줄 지정, 전체보기 시 조문 번호 자동 채움
- **즐겨찾기** (`user_favorites.json`) 및 설정 창(검색·추가·제거·적용)
- **원문 보기** — 선택 판을 브라우저로 열기
- 시점 모드 3종: 특정 시점 / 기간 / 전체 기간
- 명령줄 실행 (`run_from_command_line.py`)

### 환경 대응

- 회사 문서보안: 한글은 임시 폴더 저장 후 파이썬이 이동
- 사용자 한글 문서와 작업용 한글 인스턴스 분리
- Playwright 헤드리스(브라우저 창 숨김)
