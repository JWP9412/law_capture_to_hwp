# CHANGELOG v3.1.0

## 2026-11-20 — 3.1.0

미리보기 밑줄 다루기와 실패 기록, 저장·실행 편의성을 다듬은 작은 버전이다.

### 추가

- **캡처 실패 기록**: 밑줄 문구를 못 찾은 실패 등을 `out/실패기록/` 에 남긴다.
  - `실패기록.md` — 사람이 읽고 **피드백** 칸에 메모
  - `실패기록.jsonl` — 프로그램·AI용 한 줄 기록
  - 결과 화면 **[실패 기록 열기]**
- **문구별 밑줄 색**: Combobox 색은 *다음에 드래그할 색*만 바꾼다. 이미 고른 구간은 오른쪽 클릭 메뉴로 색을 바꾼다.
- **버튼 눌림 피드백**: 둥근 버튼을 누를 때 더 분명히 눌린 느낌이 나도록 맞췄다.
- **진행 화면 기록**: 작업 진행 메시지를 화면에 쌓아, 검은 CMD 창 없이도 무엇을 하는지 볼 수 있다.
- **숨은 콘솔**: Playwright 등 하위 프로세스의 CMD 창이 덜 뜨도록 가린다 (`core/hide_subprocess_console.py`).

### 수정

- **같은 이름 한글 파일**: 이미 있으면 `(2)`, `(3)` … 으로 바꿔 저장한다. (덮어쓰기 권한 오류를 피함)
- **미리보기 휠**: 본문이 짧아 더 안 내려갈 때 휠이 창 전체 스크롤로 넘어간다.
- **미리보기 밑줄 조작**
  - 왼쪽 클릭 → 그 표시 삭제
  - 오른쪽 클릭 → 색 바꾸기
  - 표시 위에 올리면 손가락 커서
- **실행 후 창**: 캡처가 끝난 뒤 프로그램 창이 작업표시줄에만 남아 있지 않도록 다시 앞으로 온다.
