# CHANGELOG v2.0.0

## 2026-10-16 — 2.0.0

1.0.0 이후 화면에서 바로 쓰는 기능을 한 버전으로 모았다.

### 기능

- **사용자 지정 SET**: 법령·조문·밑줄·밑줄 색을 이름으로 저장하고, 기준일만 바꿔 대기 목록에 담는다. 법령 이름이 바뀌면 안내하고 저장된 이름을 지금 이름으로 고친다.
- **밑줄 색**: 빨강·파랑·초록·주황·검정. 미리보기 형광펜과 PDF 밑줄이 같은 색이다.
- **조문 이동**: 미리보기 찾기 왼쪽 ▲ / ▼. 12조에서 ▼ 를 누르면 13조가 나온다.
- **저장된 폴더 열기**: 실행 버튼 왼쪽에서 결과 한글이 쌓이는 `out` 폴더를 연다.
- **대기 목록 여러 줄 선택**: Ctrl·Shift 로 고른 뒤 함께 지운다.
- **날짜 입력**: 슬래시, 점, `YY.MM.DD.`, `YYYY.MM.DD.`, `YY.M.D.` 처럼 적어도 같은 날로 읽는다.
- **즐겨찾기 가나다순**.
- **그림은 법령 제목부터**: 제목 위 안내문·QR은 캡처에서 뺀다.
- 미리보기 찾기(Ctrl+F), 형광펜 클릭으로 밑줄 취소.
- 이름이 바뀐 법령은 캡션에 당시 이름을 쓴다.
- 작업 표시줄에 다른 프로그램 아이콘이 뜨던 문제를 고쳤다.

### 화면

- 개정본이 하나여도 그 줄이 목록 칸 맨 위에 붙는다. 첫 항목보다 위로는 스크롤되지 않는다.
- 조문별 시행일이 어긋나던 문제를 고쳤다.
